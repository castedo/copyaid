About Copy**Ai**d.it
====================

Copy**Ai**d is inspired by and heavily influenced by:

* [manubot-ai-editor](https://github.com/greenelab/manubot-ai-editor/), and
* the preprint [A publishing infrastructure for AI-assisted academic authoring](https://doi.org/10.1101/2023.01.21.525030).

Feel free to contact [Castedo Ellerman](https://castedo.com) if you have:

* feedback or questions about Copy**Ai**d, or
* recommendations for an open-source copyediting CLI tool.
